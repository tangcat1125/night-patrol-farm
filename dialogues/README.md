# 夜巡農場對談與防衛規則

- 對談讀到最後一頁並完成，才授予線索與能力；中途關閉不算完成。
- 完成烏鴉的 crow-tracks 證詞才開放搜索。點擊地圖上的金色搜索點，或線索板的搜索按鈕，玩家會避障前往，距離 2.8 以內才採證。
- 羊的坦白需要信鴿、鴨子、烏鴉三份證詞，加上玩家親自取得的泥池羊毛與另一段路狼爪印。羊毛不是狼毛；狼存在和羊如何受傷須分開判斷。
- 動物提供的四個入口位置先記為待查證。北渠、西門、東南破牆、南果園必須親自採證，才記為已查明入口。
- 坦白後導引到牛；完成 cow-accept-apology 後，牛接受道歉，與馬組成後腿朝外的防線，貓和鴨子負責警戒。健康且未被抱起的成員才可值勤。
- 完成狗的對談啟動快速巡邏，白天巡場、夜間加速追趕野狼。
- 五個網夾是固定總量。被捕野狼跨日仍留在網中，不會自動死亡或計入消滅數；另一頭狼靠近才會撕網救援。
- 撕破的網夾在原地停用，記錄 readyRound = 當前回合 + 3；每次入夜增加一回合，滿三回合原位恢復，不補發額外庫存。占用中的網不會倒數自動放狼。
- 救援後狼群記住該入口與網夾位置，後續避開相同通路，由外圍繞行；活狼會主動接近受困同伴救援。
- 貓鴨警戒擴大牛馬攔截距離；牛馬踢擊造成傷害，兩次踢擊擊倒一狼，計入原有消滅四狼的勝利條件。保留原有動物傷亡與十回合判定。

資料：animals/*.json 為動物台詞；branches.json 為分支及條件。修改後執行 node dialogues/build-bundle.cjs 同步離線 bundle.js。
